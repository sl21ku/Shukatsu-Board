## What Was Done Today

Built the initial native iOS MVP codebase for `Shukatsu Board`.

Implemented:

- SwiftUI app shell
- SwiftData models
- Company management
- Company detail tabs
- Entry Sheet management
- Job posting management
- Task management
- Local notification scheduling
- Keychain password storage
- Face ID / Touch ID authentication before password copy
- Clipboard auto-clear after password copy
- Quick Add from pasted/shared text
- Share Extension entry point
- OCR service using Vision
- Screenshot/image OCR import from Quick Add
- Calendar event creation using EventKit
- Company comparison screen
- Demo data insertion
- Privacy manifest and permission descriptions
- GitHub repository setup
- GitHub Actions iOS CI
- Unit test for import parsing
- UI tests for launch, main navigation, and Quick Add controls

Important implementation choices:

- Passwords are not stored in SwiftData.
- Password bodies are stored only in Keychain.
- The app does not auto-login to company websites.
- Imported information is parsed into candidates and saved only after user action.
- Test runs use an in-memory SwiftData container to reduce simulator persistence warnings.
- Primary tabs are limited to five so iPhone does not collapse important tabs into `More`.
- Settings opens from the Home screen toolbar.

## Known Caveats

- The project is generated by XcodeGen. `ShukatsuBoard.xcodeproj` is not committed.
- Windows cannot run Xcode; GitHub Actions is currently the build verification path.
- OCR and Calendar services compile, but still need real simulator/device manual testing.
- Share Extension compiles, but real share-menu behavior needs Mac/Xcode or device testing.
- App Store/TestFlight signing cannot proceed until Apple Developer Program activation completes.
- Current Bundle IDs are placeholders under `com.example`.
- UI is functional MVP quality, not yet polished for App Store screenshots.
- App icon and production privacy policy URL are not yet prepared.
