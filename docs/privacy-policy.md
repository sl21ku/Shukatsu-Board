# Shukatsu Board Privacy Policy

Effective date: Draft for App Store preparation

Shukatsu Board is an iOS app for managing job-hunting information such as companies, application progress, entry sheets, job postings, deadlines, interview schedules, notes, and company my page login information.

This document is a draft privacy policy for App Store preparation. Replace the contact address and publication URL before release.

## Data Stored in the App

Shukatsu Board may store the following information entered or imported by the user:

- Company names
- Industries
- Application and selection status
- Company my page URLs
- Job posting URLs
- Login IDs
- Entry sheet questions and answers
- Job posting details
- Task titles
- Deadlines and interview dates
- Reminders
- Notes and memos

This information is stored locally on the user's device.

## Password Handling

Passwords are not stored in the app database.

Passwords for company my pages are stored in the iOS Keychain. The app stores only a Keychain identifier in its local database. Before showing or copying a saved password, the app asks for Face ID, Touch ID, or the device passcode.

Copied passwords are automatically cleared from the clipboard after a short period when possible.

## Local-First Design

Shukatsu Board is designed as a local-first app.

The current version does not send job-hunting information, entry sheet text, company login information, or imported text to an external server controlled by the app developer.

If a future version adds cloud sync, AI analysis, or external data processing, this policy and the App Store privacy information will be updated before release.

## Photos and OCR

The app may allow the user to select screenshots or images to extract text using OCR.

OCR processing is performed on the device using Apple frameworks. The selected image and recognized text are not sent to an external server by the app.

Recognized text is shown as an import candidate and is saved only after user action.

## Calendar Access

The app may request calendar access when the user chooses to add an interview, deadline, seminar, or task to the calendar.

Calendar access is used only to create events selected by the user.

## Notifications

The app may request notification permission to remind the user of deadlines, interviews, web tests, seminars, and other tasks.

Notifications are scheduled locally on the device.

## Share Extension

The app includes a Share Extension so the user can import text or URLs from Safari, Mail, Notes, LINE, or other apps.

Shared content is temporarily stored through the app group container so the main app can display import candidates. The user must confirm before saving imported information.

## Analytics and Tracking

The current version does not include third-party analytics SDKs, advertising SDKs, or cross-app tracking.

## Data Export and Deletion

The current version stores data on the user's device. Users can delete saved information from within the app by deleting companies, tasks, entry sheets, and related records.

Future versions may add export and full data deletion tools.

## Children's Privacy

Shukatsu Board is intended for students and job seekers. It is not designed for children under 13.

## Changes to This Policy

This policy may be updated as the app changes. The effective date will be updated when changes are made.
