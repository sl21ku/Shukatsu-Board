## Description

```text
Shukatsu Boardは、就活中の企業情報、選考進捗、ES、募集要項、締切、面接予定、メモをまとめて管理するためのアプリです。

企業ごとにマイページURL、ログインID、選考ステータス、志望度、ES設問、募集要項、タスクを整理できます。ホーム画面では直近の予定や未完了タスクを確認できるため、毎日やるべきことを見つけやすくなります。

主な機能:
・企業情報と選考ステータスの管理
・ES設問と回答の管理
・募集要項、勤務地、給与、福利厚生の記録
・面接、Webテスト、説明会、提出締切などのタスク管理
・ローカル通知によるリマインダー
・Safariや他アプリからの共有取り込み
・スクショ画像からのOCR取り込み
・カレンダーへの予定追加
・企業ごとの条件比較
・マイページIDとパスワードの安全な管理

パスワードはアプリ内データベースに保存せず、iOS Keychainに保存します。パスワードをコピーする前にはFace ID、Touch ID、または端末パスコードで本人確認を行います。

Shukatsu Boardはローカルファーストで設計されています。就活情報やログイン情報を外部サーバーへ送信せず、保存前にはユーザー確認を挟む方針です。
```
